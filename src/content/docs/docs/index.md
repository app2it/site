app2it is the production home for AI-built internal tools. It runs Node web apps in your own AWS account, behind your existing single sign-on, with no per-user fees.

**The code isn't public yet, so there's nothing to install today.** It will be released under Apache-2.0. There's no date yet.

## Guides on the way

- **Evaluate it:** what it is and isn't, architecture, cost, rollout and running it.
- **Review its security:** data flows, isolation, permissions, sign-in, checks, audit and known limits.
- **Build with it:** deploying your first app, yourself or with your agent.
- **Operate it:** installing, upgrading and connecting single sign-on.

Until then, the [security review page](/security/) and the [page for IT leaders](/for-it/) cover the main questions.
